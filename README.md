# handwriting_software

Software tools for online handwriting analysis and acquisition.

## Included software

- **SVC_ANALYTICS.JAR**: software for plotting and extracting features from online handwriting signals.
- **HandWritingCapturePressure.zip**: software for handwriting acquisition with Intuos Wacom tablet.

## SVC ANALYTICS

SVC ANALYTICS is a software tool for displaying and analyzing handwriting signals captured by digitizing devices. It can:

- plot online handwriting signals
- reproduce handwriting dynamically over time
- display both on-surface and in-air trajectories
- compute entropy-based measures
- compute fractal dimension measures
